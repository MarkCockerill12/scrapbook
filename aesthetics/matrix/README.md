**Fiction:** you're inside something, it noticed, and it's tracing you. Now laid out as
an operator's station rather than three floating windows.

Reworked 2026-09-28 (Mark: "make the UI a bit more diverse and interesting and easier
to see"). Panels are denser (0.94 black), text 15px, the rain sits behind a dim layer,
and the trace moved to the top where it can be seen.
