# 13 · Dead Mall — Northgate Centre, after hours

Redesigned 2026-09-28. Mark: *"needs a big redesign, make it more aesthetic and more
exploratory."* The scrolling directory page is gone; the mall is now **walkable**,
Myst-style, through 16 real photographs of real dead malls (Flickr CC via Openverse:
`dm_hall`, `dm_atrium`, `dm_escalator`, `dm_food`, `dm_store`, plus the older
`mall_atrium` / `mall_fountain` / `mall_escalator` grabs). Canvas is now `fit`.

Route (see `nodes.ts`): parking lot → north entrance → vestibule → main concourse →
west wing (Burger King) / escalators → upper level → glass arcade → the dome /
centre court → east wing → the collapsed skylight / food court → far tables /
fountain court → the 1890 arcade → palm court.
